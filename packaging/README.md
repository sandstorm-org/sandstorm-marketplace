## Author proof (run personally)

The public Keybase profile for `mnutt` returned PGP fingerprint
`211BF6A1E4CD72C957B705FA8EE8B9250C803854`. That public copy expired
on 2025-10-29. If your local key has already been renewed, publish the updated
public key to Keybase; otherwise renew it first. These commands assume the
matching private key is available in your GnuPG keyring. They may ask for its
passphrase. They do not export private key material.

```sh
cd /home/michael/p/personal/sandstorm-marketplace
gpg --quick-set-expire 211BF6A1E4CD72C957B705FA8EE8B9250C803854 2y
keybase pgp update 211BF6A1E4CD72C957B705FA8EE8B9250C803854
gpg --output packaging/author-keyring.gpg --export 211BF6A1E4CD72C957B705FA8EE8B9250C803854
printf %s 'I am the author of the Sandstorm.io app with the following ID: 3theazdrcs30r9qysmh6ks0vndm3z4xkuk6k9qmu506h7mamvqg0' |
  gpg --local-user 211BF6A1E4CD72C957B705FA8EE8B9250C803854 --output packaging/author.pgp --sign
```

If GnuPG does not have this private key, stop and use the device/key store that
does. Do not generate a replacement key just to complete these commands.
The signature must be an attached binary PGP message, not a detached signature.
The two output files contain only a public key and public author proof and may
be checked into version control. They bind the app ID, so future releases can
reuse them. Packaging includes them together and verifies the proof as part of
SPK verification. Test-key packages deliberately omit the production proof.
